# FlowTask

It exists to be the **Controlled Acceptance Fixture** for Axiom (a goal-driven autonomous software-engineering control plane): a frozen codebase with real tests that an autonomous planner can decompose, agents can modify, an independent verifier can check and an integrator can merge.
